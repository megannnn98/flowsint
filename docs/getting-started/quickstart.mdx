### Требования

Перед установкой Flowsint убедитесь, что в системе установлены:

- **Docker** и **Docker Compose**
- **Make** (для автоматизации сборки)
- **Git**

### Установка

Клонируйте репозиторий и выполните команду запуска.

```bash
git clone https://github.com/reconurge/flowsint.git
cd flowsint
make prod
```

Некоторым обогатителям нужны API-ключи. Подробнее — в [этом разделе](/docs/getting-started/enrichers#api-keys).

Приложение должно автоматически открыться по адресу http://localhost:5173.

> Образы, которые скачивает `make prod`, собраны из оригинального репозитория и показывают английский интерфейс. Русский интерфейс этого форка нужно собирать из исходников (например, `make dev`).

### Создайте первое расследование

Начните со входа или регистрации на главной странице. На панели управления создайте новое расследование, нажав «Новое расследование». Добавьте на холст первую сущность — например, доменное имя. Щёлкните сущность правой кнопкой мыши, чтобы открыть контекстное меню, и запустите обогатитель. По мере появления результатов изучайте найденные сущности и связи прямо на графе.

### Запуск первого обогатителя

Для начала можно найти поддомены домена.

Добавьте в расследование сущность-домен, например `example.com`, затем щёлкните правой кнопкой мыши по узлу домена и выберите обогатитель «domain_to_subdomains». Дождитесь завершения работы обогатителя: найденные поддомены будут добавлены на граф, и вы сможете их просмотреть.

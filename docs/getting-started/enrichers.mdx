### Что такое обогатитель?

Обогатитель (Enricher) — это операция, которая по входному элементу A (исходной сущности) создаёт один или несколько элементов B (целевых сущностей), применяя метод поиска или сопоставления, называемый пивотом (pivot).

Пример:

```bash
A = my.domain.com (доменное имя)
    ↓
p = «DNS-разрешение» (пивот)
    ↓
B = 12.23.34.45 (IP-адрес)
```

Иначе говоря, пивот — это метод или технический процесс, с помощью которого из A получают B. Пивот определяет, как преобразование получает результат (например, DNS-разрешение, WHOIS-запрос, запрос к API и т. д.).

Пример:

```bash
DNS Resolution → домен → IP
    ↓
WHOIS Lookup → IP → владелец
    ↓
Reverse Image Search → изображение → веб-страницы, содержащие это изображение
```

Flowsint поставляется с набором готовых обогатителей, разделённых на несколько категорий. Эти обогатители могут использовать стандартные пивоты, которые ваша машина поддерживает по умолчанию (DNS-разрешение, WHOIS-запрос и т. д.), и другие, зависящие от внешних инструментов.

Это могут быть:

- Нативные: DNS-разрешение, Whois и т. д.
- Docker-инструменты: [subfinder](https://github.com/projectdiscovery/subfinder), [asnmap](https://github.com/projectdiscovery/asnmap) и т. д.
- Python-инструменты: [sherlock](https://github.com/sherlock-project/sherlock), [maigret](https://github.com/soxoj/maigret), [reconurge/recontrack](https://github.com/reconurge/recontrack), [reconurge/reconcrawl](https://github.com/reconurge/reconcrawl), [reconurge/reconspread](https://github.com/reconurge/reconspread) и т. д.
- Внешние сервисы (платные и бесплатные): [shodan](https://www.shodan.io/), [whoxy](https://www.whoxy.com/), [whoisxmlapi](https://www.whoisxmlapi.com) и т. д.

### Создание собственных обогатителей

Создание собственных обогатителей включает несколько шагов и не такое уж простое.

Если вы планируете писать собственные обогатители и думаете, что они могут пригодиться сообществу, пожалуйста, внесите вклад — отправьте pull request!

Чтобы начать создавать собственные обогатители, обратитесь к [этому разделу](/docs/developers/managing-enrichers).

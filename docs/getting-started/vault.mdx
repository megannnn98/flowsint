## Что такое Vault

Многим инструментам, которыми вы будете пользоваться во Flowsint, нужны API-ключи сторонних сервисов.

**Хранилище (Vault)** (по-французски *«Coffre fort»*) — это место, где такие API-ключи собираются и надёжно хранятся.
Работаете ли вы с локальным экземпляром Flowsint или с полностью развёрнутым в распределённой системе, ключи должны храниться безопасно.

## Добавление ключа

В экосистеме обогатителей Flowsint API-ключи подчиняются определённому формату: они пишутся заглавными буквами и имеют говорящее имя вида `<service>_API_KEY`.

## Текущие ограничения

Пока что сопоставить конкретный ключ из хранилища с обогатителем **прямо в интерфейсе** нельзя. Обогатитель сам объявляет имя нужной ему переменной с API-ключом, например так (в ядре обогатителя):

```python
@classmethod
    def get_params_schema(cls) -> List[Dict[str, Any]]:
        """Declare required parameters for this enricher"""
        return [
            {
                "name": "PDCP_API_KEY",
                "type": "vaultSecret",
                "description": "The ProjectDiscovery Cloud Platform API key for asnmap.",
                "required": True,
            },
        ]
```

Это известное ограничение, мы работаем над его устранением.

А пока вот список ключей, необходимых, чтобы Flowsint работал в полную силу:

```bash
# for enrichers
WHOXY_API_KEY # Whoxy domain search engine [WHOXY]
PDCP_API_KEY # ProjectDiscovery Cloud Platform [ASNMAP], [NAABU] etc
HIBP_API_KEY # HaveIBeenPwned API key [HIBP]
ETHERSCAN_API_KEY # Etherscan crypto API key [ETHERSCAN]
# for Flo, AI assistant
MISTRAL_API_KEY
# but other providers will be supported soon (ChatGPT, etc.)
```

Есть и другие инструменты, которым могут понадобиться иные API-ключи, например [Subfinder](https://github.com/projectdiscovery/subfinder). Настроить их пока нельзя, но скоро это станет возможным.

Следите за обновлениями: эти механизмы могут измениться, ведь цель — сделать работу с программой максимально удобной.
